# TC-001: Успешный вход с валидными учетными данными

| Элемент | Описание |
| :--- | :--- |
| Предусловия | Пользователь зарегистрирован (логин: user@example.com, пароль: Pass123!), сервис доступен, используется браузер на ПК |

# TC-002: Вход с неверным паролем (безопасность, brute-force защита)

| Элемент | Описание |
| :--- | :--- |
| Предусловия | Пользователь зарегистрирован |
| Шаги | 1. Ввести верный логин user@example.com и неверный пароль wrong. 2. Нажать «Войти». |
| Ожидаемый результат | Ошибка «Неверный логин или пароль». Счётчик попыток входа увеличен. |

# TC-003: Блокировка после N неудачных попыток (brute-force)

| Элемент | Описание |
| :--- | :--- |
| Предусловия | Включена защита от brute-force (5 попыток) |
| Шаги | 1. Выполнить 5 входов подряд с верным логином и разными неверными паролями. 2. На 6-й попытке ввести верный пароль. |
| Ожидаемый результат | Учётная запись временно заблокирована (например, на 15 минут). Даже с верным паролем вход отклоняется. |

| Ожидаемый результат | Ошибка «Учётная запись заблокирована. Обратитесь к администратору». |

# TC-005: Управление сессией — вход с двух разных устройств (мультиаутентификация)

# TC-006: Завершение сессии на одном устройстве с другого
